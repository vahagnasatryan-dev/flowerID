# Цветочный портрет

Frontend MVP интерактивной формы по ТЗ: mobile-first квиз с локальным сохранением, расчетом архетипа, финальным портретом, ТЗ для флориста, копированием, шарингом и локальным экспортом.

## Запуск

В проекте ожидается обычный Node.js toolchain:

```bash
npm install
npm run dev
```

Затем откройте адрес, который покажет Vite.

## Сборка

```bash
npm run build
```

## Что реализовано

- 10 экранов квиза из ТЗ.
- 12 визуальных карточек букетов с локальными стилизованными MVP-визуалами.
- Свайпы мышью/тачем и кнопки реакций.
- Ограничение выбора настроений 1-3.
- Палитры с режимами `Нравится`, `Идеально`, `Не мое`.
- Цветочный кастинг с реакциями `Люблю`, `Нормально`, `Не люблю`, `Нельзя`.
- Практичные ограничения: аромат, стойкость, животные, аллергии.
- Упаковка, стоп-лист упаковки, личные ассоциации и контактный экран.
- Локальное сохранение прогресса в `localStorage`.
- Локальный scoring 10 архетипов и гибридный результат при близких баллах.
- ТЗ для флориста, включая предупреждение про конфликт `лилии + кошка`.
- Безопасная публичная ссылка `/p/{payload}` без телефона, Telegram и медицинских комментариев.
- Web Share API с fallback на копирование.
- Экспорт результата в JSON и CSV.
- Локальный массив событий `quiz_events` в `localStorage`.
